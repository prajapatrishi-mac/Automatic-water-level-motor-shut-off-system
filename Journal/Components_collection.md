# Journal 2 – Component Collection

**Project Name:** Automatic Water Level Motor Shut-Off System
Step: Component Collection
Time Spent: 1 Hour

## Components Collected

After completing the project planning, I started collecting the components required for my project. I checked the available components and arranged them so I could use them during the next steps.

The components I planned to use are:

1. Arduino Uno
2. Sensor for detecting the water level
3. Lithium-ion battery
4. Connecting wires
5. Relay module
6. Switch
7. DC motor or water pump
