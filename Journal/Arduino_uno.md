# Journal 3 – Arduino UNO Code Compilation

**Project Name:** Automatic Water Level Motor Shut-Off System
Step: Arduino UNO Code Compilation
Time Spent: 2 Hour

## Work Done

In this step, I used my phone to work on the Arduino code with the help of the ArduinoDroid app. I prepared the code for my Automatic Water Level Motor Shut-Off System and checked it using the compile option in the app.

I am using Arduino UNO as the main controller. The code is being prepared to read the sensor input and control the relay connected to the motor. The aim is to switch off the motor when the required water level is detected.

I used ArduinoDroid because I wanted to write and compile the code directly from my phone without needing a computer.
