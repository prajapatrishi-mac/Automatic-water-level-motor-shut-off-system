# Journal 4 – Wiring and Project Assembly

**Project Name:** Automatic Water Level Motor Shut-Off System
Step: Wiring and Project Assembly
Time Spent: 2 Hours

## Work Done

In this step, I started connecting the components according to my project plan. I connected the Arduino UNO, sensor, relay module, switch, battery, and motor using connecting wires.

After completing the wiring, I checked the connections to make sure everything was properly connected. I arranged the components so the project looked neat and was easier to test.

The main goal was to make the motor switch off automatically when the required water level was detected. I checked the setup and prepared it for testing.

This step took around 2 hours because I needed time to arrange the components, complete the wiring, and check the connections.

## Result

The wiring and assembly stage is complete. The next step is to test the project and check whether the motor switches off as intended.
