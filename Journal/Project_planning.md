# Journal 1 – Project Planning

**Project Name:** Automatic Water Level Motor Shut-Off System
Step: Project Planning
Time Spent: 1.5 Hour

## 1. Project Overview

I started planning my project, which is an automatic water level motor shut-off system. The main idea is to detect the water level in a container and automatically switch off the motor when the required level is reached. I am planning to use an Arduino Uno to control the system and a relay module to control the motor. This project is designed to help prevent water overflow and save water.

## 2. Main Features

- Detect the water level in a container.
- Automatically control the motor.
- Switch off the motor when the required water level is reached.
- Use an Arduino Uno and relay module.
- Keep the project simple and low-cost.

## 3. Components Required

1. Arduino Uno
2. Soil moisture sensor (initially planned; suitability for water-level detection needs checking)
3. Lithium-ion battery
4. Connecting wires
5. Relay module
6. Switch
7. DC motor or water pump
