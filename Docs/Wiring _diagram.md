# Wiring Diagram

## Project
Automatic Water Level Motor Shut-Off System

## Components
- Arduino UNO
- Water-level sensor (to be verified)
- Relay module
- DC motor or water pump
- Lithium-ion battery
- Switch
- Connecting wires

## Wiring Notes
The sensor will provide an input to the Arduino UNO.
The Arduino will control the relay according to the
sensor reading. The relay will control the motor.

The exact pin connections will be added after checking
the sensor model and completing the circuit.
