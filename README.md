# Automatic-water-level-motor-shut-off-system

## About the Project

This is my Arduino UNO project. The main idea is to detect the water level in a container and automatically switch off a motor or water pump when the required level is reached.

I am building this project using an Arduino UNO, a sensor, a relay module, a battery, a switch, connecting wires, and a motor.

## Features

- Detect the required water level using a suitable sensor.
- Control a motor through a relay module.
- Automatically switch off the motor when the set condition is reached.
- Use simple and affordable components.

## Components Required

- Arduino UNO
- Water-level sensor
- Relay module
- Lithium-ion battery
- Connecting wires
- Switch
- DC motor or water pump

## How It Should Work

The sensor provides input to the Arduino UNO. The Arduino checks the sensor reading and controls the relay according to the program. When the required water level is detected, the system is intended to switch off the motor.

The automatic shut-off function will be confirmed through testing.
